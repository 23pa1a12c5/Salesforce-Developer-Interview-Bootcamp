# Day 1 – Salesforce Fundamentals

## Objective

Learn the fundamentals of Salesforce development by implementing SOQL, Apex Classes, Apex Triggers, Trigger Handler Pattern, and Lightning Web Components (LWC).

---

## Topics Covered

- SOQL
- Apex Classes
- Apex Triggers
- Trigger Handler Pattern
- Lightning Web Components (LWC)

---

## Practical Tasks Completed

### 1. SOQL

Executed SOQL queries to retrieve Vehicle records from Salesforce.

### 2. Apex Controller

Created a VehicleController Apex class to fetch Vehicle records.

### 3. Apex Trigger

Implemented a Trigger on the Vehicle object.

### 4. Trigger Handler

Separated business logic using the Trigger Handler pattern.

### 5. Lightning Web Component

Created an LWC named **vehicleDetails** to display Vehicle information.
