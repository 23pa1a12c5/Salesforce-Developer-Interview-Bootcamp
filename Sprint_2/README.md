# Day 2 – Apex Advanced Concepts

## Objective

Learn advanced Apex programming concepts including Collections, Governor Limits, Future Apex, and Parent–Child Lightning Web Component communication.

---

## Topics Covered

- Apex Collections (List, Set, Map)
- Governor Limits
- Future Apex
- Parent–Child LWC Communication

---

## Practical Work

### Collections

Practiced List, Set, and Map collections in Apex.

### Governor Limits

Learned Salesforce execution limits and best practices.

### Future Apex

Implemented asynchronous Apex methods using the @future annotation.

### Parent–Child LWC

Built Lightning Web Components demonstrating communication between parent and child components.
